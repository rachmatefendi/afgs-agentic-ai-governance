# AFGS v1.0 — Conformance test availability

**An executable AFGS conformance suite is not supplied.**

The source identifies the missing executable Conformance Test Profile as KL-R5 (§20.4), with implementation in §21, Step 4.

The [threat model](../specification/threat-model.md) describes test targets. The [evaluation document](../research/evaluation.md) contains proposed criteria, not results from an executed benchmark.

No fixture files, passing badges or CI results are provided as substitutes for those tests. File-integrity checks do not establish SC1/SC2/SC3 conformance or validate a runtime, registry or execution gateway.
