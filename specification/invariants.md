# AFGS v1.0 — Cross-pillar invariants

**Source:** Frozen normative specification §15, pp. 20–21.  
**Representation:** Source-text transcription with table formatting normalized; not a new normative revision.

The source contains **GS-I1–GS-I12**. The invariant section is reproduced in [the technical source excerpts](../provenance/AFGS-v1.0-source-excerpts.txt). Section references such as §11.6 below refer to the source specification, not this file.

| ID | Invariant | Normative rule |
| --- | --- | --- |
| GS-I1 | Authority Non-Creation | No model, skill, router, or pillar may create organizational authority. |
| GS-I2 | State Jurisdiction | Each pillar may mutate only the state it owns. |
| GS-I3 | No Execution by Analysis | Analytical correctness or persuasive reasoning does not imply execution permission. |
| GS-I4 | No Material Decision Bypass | Mandatory MDGR triggers cannot be downgraded by ordinary generative reasoning. |
| GS-I5 | Evidence by Reference | Material claims remain provenance-linked across handoffs. |
| GS-I6 | No Silent Condition Loss | PERMIT-C binding conditions survive every downstream handoff and token-binding step. |
| GS-I7 | Execution Freshness & Consistency | Execution is denied for expired, revoked, replayed, scope-mismatched, or state/policy/authority-stale permission; PECG must revalidate before controlled egress, served per §11.6 and evaluated against trusted time per §11.7. |
| GS-I8 | Human Authority Preservation & Governed Override | AI cannot substitute for legally/organizationally required human authority; human overrides require authenticated, jurisdiction-valid, auditable governance transitions; non-derogable constraints remain non-overridable. |
| GS-I9 | Honest Conformance / Claim Discipline | A deployment cannot claim enforcement stronger than its actual substrate and test evidence. |
| GS-I10 | Immutable Decision History | Revalidation, appeal, revocation, and override create new state transitions rather than rewriting prior records. |
| GS-I11 | Independent Materiality Interception | Mandatory material-decision triggers cannot depend solely on AI Founder OS classification or model self-assessment. |
| GS-I12 | No Self-Sufficient Governance Authority | No probabilistic reasoning component may independently establish the binding state, authority, constraint satisfaction, or execution eligibility on which its own verdict depends. Machine-evaluable binding constraints require deterministic external validation; interpretation-required constraints require authenticated, jurisdiction-valid human authority or another explicitly authorized non-self-validating control. |

These are specified requirements. Their presence in a document is not evidence that a runtime enforces them. Apply the [conformance criteria](conformance.md) before making a deployment claim.
