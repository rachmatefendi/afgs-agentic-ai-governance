# AFGS v1.0 — Runtime availability

**No AFGS reference runtime is supplied.**

The source roadmap assigns SC2 registries, validator middleware and a state engine to Step 3; SC3 controlled egress, PECG/PESR, tokens, revocation, idempotency, reconciliation and trusted-time infrastructure to Step 5.

This repository contains no installable SDK, agent runtime, deployed service, authority database or production adapter. It does not select a vendor, model or runtime platform.

An implementation must declare the controls it actually enforces and the evidence supporting those claims. It must remain distinguishable from the normative specification. See [roadmap](../research/roadmap.md), [conformance](../specification/conformance.md) and [contract inventory](../schemas/README.md).
