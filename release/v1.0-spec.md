# v1.0-spec

**AFGS version:** v1.0  
**Distribution:** Publication paper and non-normative companion documentation

This distribution contains the original AFGS paper, selected technical source excerpts, architecture references, GS-I1–GS-I12, SC0–SC3 conformance criteria, T01–T15, six illustrative JSON contract objects, and implementation/evaluation documentation.

It is **not a verified canonical frozen-baseline distribution or an implementation release**. The source declares **SC0 / SC1-capable**. No deployed SC1 compliance, SC2/SC3 enforcement, empirical effectiveness, independent human peer review or external certification is demonstrated by these files.

## Artifact identity

The canonical normative DOCX is not included and its source-declared SHA-256 is not verified. The original 14-page paper PDF and selected technical passages from the 33-page source are separate artifacts. The excerpts are not the complete transcript and do not replace or authenticate the canonical DOCX.

Artifact identities and inclusion scope are recorded in `provenance/manifest.json`. File checksums are in `SHA256SUMS`.
